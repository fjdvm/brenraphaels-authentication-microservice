## Outstanding full-flow benchmark

The saved Super Admin credentials returned **Invalid credentials** on the staged deployment. No existing User's password, Role, or AccessGrants was changed. A working Administrator login and an operator-controlled test inbox are needed to collect the successful sign-in, sign-out, password flows, System cards, Users list first visit/revisit, create User, edit AccessGrants, delete/restore, resend credentials, and System Logs/My Logs load/filter timings. These remain unmeasured; #89's full after-region timing criterion is outstanding.

During failed sign-in attempts, runtime logs recorded `Failed to record audit event` with `TimeoutError` in `sin1`. This is an observed dependency failure, not evidence of a successful sign-in duration or proof that the region caused it. Investigate it when repeating the authenticated benchmark; it could affect action timings and audit availability.
